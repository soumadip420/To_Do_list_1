# My Todo List

A clean, responsive, and user-friendly web application designed to help users efficiently manage their daily tasks, objectives, and project timelines.

## 🚀 Features

- **Detailed Task Creation:** Input task names, descriptions, and specific objectives.
- **Timeline Tracking:** Set clear `Start Date` and `End Date` parameters for every task.
- **Difficulty Grading:** Categorize your tasks by complexity levels: `Easy`, `Medium`, or `Hard`.
- **Smart Filtering:** Quickly view your tasks using built-in filters: `All`, `Active`, and `Completed`.
- **Progress Tracking:** Dynamic real-time counter showing exactly how many tasks are remaining.
- **Bulk Cleanup:** Clear out all finished objectives instantly using the `Clear Completed` utility.

## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure for the task dashboard.
- **CSS3:** Modern UI layout utilizing custom grid/flexbox properties and a vibrant color scheme.
- **JavaScript (ES6+):** Dynamic task management, status filtering, and localized event handling.

## 📦 Installation & Local Setup

Follow these simple steps to run this project locally on your machine:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the Directory:**
   ```bash
   cd to_do_list
   ```

3. **Launch the Application:**
   Simply double-click the `index.html` file to open it directly in your preferred web browser.
